# PiLog Learning Hub

Enterprise Learning Platform for Data Quality, Governance, Asset Information Management, Vendor Governance, Material Governance, SAP Integration, AI, Analytics, and Digital Transformation.

## Tech stack

- Vite + React + TypeScript
- Tailwind CSS + shadcn/ui
- Supabase (auth, database, storage, edge functions)

## Local development

```sh
npm install
npm run dev
```
